【画像ファイルの差し替えについて】
=======================================

以下の画像ファイルを用意して、このフォルダに配置してください。

■ 必須
---------------------------------------
hero-bg.jpg       背景画像（知多の風景・作業風景）※画像がない場合はグラデーション表示
hero-visual.jpg   PC表示時のヒーロー右側ビジュアル（代表写真・作業写真）推奨：縦長
profile.jpg       代表プロフィール写真（円形表示）推奨サイズ：200×200px以上
ogp.jpg           SNSシェア時のOGP画像　推奨サイズ：1200×630px

■ 推奨
---------------------------------------
line-qr.png       LINEの友だち追加QRコード（LINE公式アカウント管理画面から取得）
favicon.ico       ファビコン（16×16 と 32×32 を含む .ico ファイル）

■ 将来追加可能な作業写真
---------------------------------------
case-01.jpg       事例1の作業写真（解体・外構）
case-02.jpg       事例2の作業写真（片付け）
case-03.jpg       事例3の作業写真（抜根）

=======================================
【LINEリンクの差し替え】
index.html と js/main.js 内で
  https://line.me/ti/p/XXXXXXXXXX
を検索して、実際のLINE公式アカウントURLに一括置換してください。

【電話番号の差し替え】
index.html 内で
  tel:XXXXXXXXXX  →  実際の電話番号（例：tel:0562-XX-XXXX）
  0XXX-XX-XXXX   →  実際の電話番号表示テキスト
を検索して置換してください。

【本番URLの差し替え】
index.html の先頭付近にある
  https://chita-naoyuki.com/
を実際のドメインに変更してください（canonical・OGP）。
